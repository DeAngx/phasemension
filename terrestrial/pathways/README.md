# pathways

Connectivity through volume.

Central orientation question: what would make a tunnel (or sustained pathway) from one side of the Earth to the other *conceptually coherent* — not as engineering fantasy, but as a question about density, pressure, phase, geometry, and continuous addressability across planetary interior?

This folder collects notes on existing natural pathways (fluid migration, melt channels, fracture networks, high-pressure phase boundaries as transport routes) and on the minimal conceptual requirements for a sustained through-volume path.

If that question gains structure, working backward becomes useful.
