# terrestrial

Primary data and model source: what Earth already does.

Water, crystals, pressure regimes, phase behavior across depth, connected volumes, and planetary-scale reorganization of matter. Four classical stages of matter are not enough — we need an intra-planetary reading of density, geometry, and connectivity.

Subfolders:
- `hydrosphere/` — water in all its planetary forms and transitions
- `crystals/` — ordered solids, growth, anisotropy, memory of prior states
- `pathways/` — connectivity questions (including the through-Earth tunnel orientation)

This is not geology tourism. It is the search for existing mechanisms that already solve (or partially solve) addressable density and sustained pathways through volume.
