# interfaces

Programmable surfaces and density fields.

Surface is not only a boundary; it can be an addressable object. Density can be driven rather than treated as a passive material property. This folder is for models and sketches where interface geometry, curvature, anisotropy, and local density are controllable and can talk to each other.

Links to phase-field / level-set methods, anisotropic surface energy (faceting), and any continuum description that treats the boundary as first-class.
